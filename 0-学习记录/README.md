# ROS2 学习记录

这个目录用于记录 ROS2 学习项目从环境搭建到跑通 demo 的全过程。建议每次动环境、跑命令、遇到报错时都留下记录，方便复盘。

## 目录约定

- `daily/`: 每日推进记录，写当天做了什么、验证结果、下一步。
- `notebooks/`: 实验型笔记或 Jupyter Notebook。
- `screenshots/`: WSLg、RViz、Gazebo、TurtleBot3 等 GUI 运行截图。
- `01-环境搭建-WSL2-Ubuntu2404.md`: WSL2 + Ubuntu 24.04 环境搭建主记录。
- `02-ROS2-Jazzy安装.md`: ROS 2 Jazzy Desktop 安装与验证记录。
- `03-ROS2机器人开发基础.md`: ROS2 工作空间、功能包、节点、编译、运行最小闭环。
- `04-TurtleBot3基础操控.md`: TurtleBot3/Gazebo 安装、启动、控制和验证记录。
- `阶段总结-从WSL到ROS2开发基础.md`: 当前阶段的完成事项、坑点和常用命令汇总。
- `命令记录.md`: 常用命令和已执行命令。
- `坑点记录.md`: 报错、原因判断、解决方案。

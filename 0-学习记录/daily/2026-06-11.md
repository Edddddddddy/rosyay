## 踩坑

- 从 PowerShell 调 WSL 时，`$HOME`、`$t`、`$!`、`$(...)` 容易被 PowerShell 抢先展开。
- 教程里的 Gazebo 旧包名要按 Jazzy/Harmonic 改成 `gz-harmonic` 和 `ros-jazzy-ros-gz`。
- `ros_gz_sim_demos diff_drive` 的速度话题是 `Twist`，TurtleBot3 的 `/cmd_vel` 是 `TwistStamped`。
- Navigation2 启动后没有初始位姿时，`map -> base_link` 不存在是正常现象，需要用 RViz 的 `2D Pose Estimate` 或命令行发布 `/initialpose`。
- 复杂 ROS2 YAML 消息跨 PowerShell/WSL 容易被引号破坏，必要时用 `rclpy` 小脚本发布。
- Gazebo Harmonic 插件名要使用 `gz-sim-*` 当前写法。
- URDF 根 link 不建议带惯性，增加 `base_footprint` 更稳。
- ament `uncrustify` 对短 lambda 格式严格，需要按工具输出修。

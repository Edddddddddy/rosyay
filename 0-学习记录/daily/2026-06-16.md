## 踩坑

- 课程源码的 `differential_drive_robot` 安装规则引用了不存在的 `include/` 和 `rviz/` 目录。
- `colcon test` 失败数量很多，但主要是 lint，不代表节点不可运行。
- `navigation_action_client` 没有自动退出逻辑，命令行测试需要手动中断。
- action server 被强制停止时，detached thread 可能触发 `Asked to publish result for goal that does not exist`。
- PowerShell 调 WSL 时偶尔出现乱码的 WSL NAT / localhost 提示，exit code 为 0 时不影响本次 ROS 运行判断。

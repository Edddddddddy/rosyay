# 03 ROS2 机器人开发基础

日期：2026-06-11

目标：按照 ROS2 机器人开发流程，完成一次从工作空间到功能包、源码、编译、运行的最小闭环。

## 开发流程

ROS2 机器人开发的基本循环：

1. 创建工作空间。
2. 创建功能包。
3. 编写源代码。
4. 设置编译规则。
5. 编译和调试。
6. 运行功能。

本次实操创建了：

- 工作空间：`~/ros2_ws`
- 功能包：`my_package`
- 节点：`learning_talker`
- 话题：`/learning_chatter`

## 1. 创建工作空间

```bash
mkdir -p ~/ros2_ws/src
cd ~/ros2_ws
```

生成后的典型目录：

```text
~/ros2_ws/
├── src/
├── build/
├── install/
└── log/
```

说明：

- `src/`: 放源码包。
- `build/`: colcon 编译中间产物。
- `install/`: 编译安装后的可运行内容。
- `log/`: 编译日志。

## 2. 创建功能包

```bash
cd ~/ros2_ws/src
ros2 pkg create --build-type ament_python my_package --dependencies rclpy std_msgs
```

本次创建的是 Python 包，依赖：

- `rclpy`: ROS2 Python 客户端库。
- `std_msgs`: 标准消息类型，本次使用 `std_msgs/msg/String`。

## 3. 编写源代码

节点文件：

```text
~/ros2_ws/src/my_package/my_package/learning_talker.py
```

功能：

- 创建名为 `learning_talker` 的节点。
- 每秒向 `/learning_chatter` 发布一条字符串消息。
- 同时通过日志输出发布内容。

核心概念对应：

- Node：`LearningTalker`
- Topic：`learning_chatter`
- Message：`std_msgs.msg.String`
- Timer：每 1 秒触发一次发布回调。

## 4. 设置编译规则

修改 `setup.py`，增加入口点：

```python
entry_points={
    'console_scripts': [
        'learning_talker = my_package.learning_talker:main',
    ],
},
```

这样编译安装后可以用以下命令运行：

```bash
ros2 run my_package learning_talker
```

同时整理了 `package.xml`：

- description：`Minimal ROS2 learning package for workspace/package/node flow.`
- license：`Apache-2.0`
- depend：`rclpy`、`std_msgs`

## 5. 编译和调试

```bash
cd ~/ros2_ws
colcon build --symlink-install
```

结果：

```text
Starting >>> my_package
Finished <<< my_package
Summary: 1 package finished
```

`--symlink-install` 适合 Python 学习开发：改源码后通常不需要重新复制安装文件，调试更顺手。

## 6. 功能运行

source 环境：

```bash
source /opt/ros/jazzy/setup.bash
source ~/ros2_ws/install/setup.bash
```

运行节点：

```bash
ros2 run my_package learning_talker
```

验证话题：

```bash
ros2 topic echo /learning_chatter --once
```

本次验证结果：

```text
[learning_talker]: Publishing: "hello ros2 dev flow #1"
data: 'hello ros2 dev flow #3'
```

## 3.3.2 创建功能包

### Python 功能包创建

课程里不重点讲 Python 包，这里只保留命令认识。

创建基础 Python 包：

```bash
cd ~/ros2_ws/src
ros2 pkg create --build-type ament_python my_python_pkg
```

创建带依赖的 Python 包：

```bash
ros2 pkg create --build-type ament_python my_python_pkg \
  --dependencies rclpy std_msgs sensor_msgs geometry_msgs
```

创建带节点的 Python 包：

```bash
ros2 pkg create --build-type ament_python my_python_pkg \
  --dependencies rclpy std_msgs \
  --node-name my_node
```

注意：命令里的 `\` 是 Linux shell 的换行续写符，`\` 后面不要加空格。如果在一行里写，可以去掉 `\`。

### C++ 功能包创建

课程主线使用 C++。本次创建了 C++ 包：

```bash
cd ~/ros2_ws/src
ros2 pkg create --build-type ament_cmake my_cpp_pkg \
  --dependencies rclcpp std_msgs sensor_msgs geometry_msgs \
  --node-name my_node
```

生成目录：

```text
~/ros2_ws/src/my_cpp_pkg/
├── CMakeLists.txt
├── include/my_cpp_pkg/
├── package.xml
└── src/my_node.cpp
```

本次把默认 `hello world` 节点改成了 C++ 发布节点：

- 包名：`my_cpp_pkg`
- 节点名：`my_node`
- 话题：`/cpp_chatter`
- 消息类型：`std_msgs/msg/String`
- 发布频率：1 秒一次

`package.xml` 已整理：

- description：`Minimal C++ ROS2 package for package creation and build practice.`
- license：`Apache-2.0`
- depend：`rclcpp`、`std_msgs`、`sensor_msgs`、`geometry_msgs`

`CMakeLists.txt` 由 `ros2 pkg create` 自动生成，关键点：

```cmake
find_package(rclcpp REQUIRED)
find_package(std_msgs REQUIRED)

add_executable(my_node src/my_node.cpp)
ament_target_dependencies(
  my_node
  "rclcpp"
  "std_msgs"
  "sensor_msgs"
  "geometry_msgs"
)

install(TARGETS my_node
  DESTINATION lib/${PROJECT_NAME})
```

## 3.3.4 编译功能包

### 编译指定功能包

编译 C++ 包：

```bash
cd ~/ros2_ws
colcon build --symlink-install --packages-select my_cpp_pkg
```

结果：

```text
Starting >>> my_cpp_pkg
Finished <<< my_cpp_pkg
Summary: 1 package finished
```

编译多个指定包：

```bash
colcon build --symlink-install --packages-select my_package my_cpp_pkg
```

编译包及其依赖：

```bash
colcon build --packages-up-to my_cpp_pkg
```

编译修改过的包：

```bash
colcon build --packages-changed
```

### 编译所有功能包

基础命令：

```bash
colcon build
```

常用选项：

```bash
colcon build --event-handlers console_direct+
colcon build --parallel-workers 4
colcon build --symlink-install
colcon build --cmake-args -DCMAKE_BUILD_TYPE=Debug
```

注意：当前 `src/` 中克隆了 `ros2/examples`。直接全量 `colcon build` 会尝试编译 examples 中很多包，且可能覆盖 ROS Desktop 已安装示例包。学习阶段优先用 `--packages-select`。

### 清除编译历史

这些命令会删除编译产物，执行前要确认当前目录是 `~/ros2_ws`：

```bash
cd ~/ros2_ws
rm -rf build/ install/ log/
```

删除指定包的编译文件：

```bash
rm -rf build/my_cpp_pkg/ install/my_cpp_pkg/
```

清理 Python 字节码：

```bash
find . -name "*.pyc" -delete
find . -name "__pycache__" -type d -exec rm -rf {} +
```

本次没有执行删除类命令，只记录用法。

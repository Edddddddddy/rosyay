## 二、编译流程

基础环境：

```bash
source /opt/ros/jazzy/setup.bash
cd /home/ubuntu/ros2-src
```

第一次编译：

```bash
colcon build --symlink-install --event-handlers console_direct+
```

结果：大部分包成功，`differential_drive_robot` 失败。原因是它的 `CMakeLists.txt` 安装了 `include/` 和 `rviz/` 目录，但源码里缺少这两个目录。

修复方式：

```bash
mkdir -p /home/ubuntu/ros2-src/differential_drive_robot/include/differential_drive_robot
mkdir -p /home/ubuntu/ros2-src/differential_drive_robot/rviz
```

重新编译失败包：

```bash
colcon build --symlink-install --packages-select differential_drive_robot --event-handlers console_direct+
```

最终全量确认：

```bash

```

结果：

结论：课程源码已经可以在当前 WSL2 + ROS2 Jazzy 环境中完成全量编译。

## 五、踩坑记录

### 1. `differential_drive_robot` 缺少安装目录

现象：

```text
ament_cmake_symlink_install_directory() can't find
/home/ubuntu/ros2-src/differential_drive_robot/include/
```

后续又遇到：

```text
can't find .../differential_drive_robot/rviz/
```

处理：

```bash
mkdir -p /home/ubuntu/ros2-src/differential_drive_robot/include/differential_drive_robot
mkdir -p /home/ubuntu/ros2-src/differential_drive_robot/rviz
```

原因：CMake 安装规则写了这些目录，但课程源码没有提交空目录。

### 2. `colcon test` 红灯不等于不能运行

课程源码的 lint 失败很多，尤其是 Python launch 文件、C++ 格式、版权检查和 CMake lint。

当前学习处理方式：

- 先用 `colcon build` 和代表性节点烟测确认功能链路。
- 如果以后要把课程源码合并进自己的项目，再逐个包修 lint。

### 3. action 示例不适合直接用 `timeout` 强停

`navigation_action_client` 没有自动退出；server 使用 detached thread 执行目标。强行中断时可能出现：

```text
Asked to publish result for goal that does not exist
```

学习结论：action 示例已经能注册、接收目标、反馈进度；但如果作为工程代码，需要补充更干净的 shutdown / cancel 逻辑。

### 4. WSL 输出里有乱码 warning

现象：PowerShell 调 WSL 时偶尔出现一段乱码的 `wsl: ... localhost ... WSL NAT ...`。

处理：只要命令 exit code 为 0，且 ROS 日志正常，可先视为 WSL/PowerShell 输出编码或网络提示问题；不要把它误判为 ROS 编译失败。

### 5. 课程源码目录会产生 build/install/log

`colcon build` 会在 `/home/ubuntu/ros2-src` 下生成：

```text
build/
install/
log/
```

这些是构建产物，不要提交进自己的学习文档仓库。课程源码本身当前也出现了未跟踪的构建产物，这是正常现象。

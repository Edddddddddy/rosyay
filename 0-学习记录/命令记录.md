# 命令记录

## 2026-06-10 WSL2 / Ubuntu 24.04

查询 WSL：

```powershell
wsl --status
wsl --list --verbose
wsl --list --online
wsl --version
```

尝试安装 Ubuntu 24.04：

```powershell
wsl --install -d Ubuntu-24.04 --no-launch
wsl --install Ubuntu-24.04 --no-launch
```

通过 winget 安装 Ubuntu 24.04 LTS：

```powershell
winget search "Ubuntu 24.04"
winget install --id Canonical.Ubuntu.2404 --exact --accept-source-agreements --accept-package-agreements --silent
```

检查 Ubuntu 应用包：

```powershell
Get-AppxPackage *Ubuntu* | Select-Object Name,PackageFullName,InstallLocation,Status
Get-ChildItem $env:LOCALAPPDATA\Microsoft\WindowsApps\*ubuntu*
```

注册/启动测试：

```powershell
ubuntu2404.exe
wsl -d Ubuntu-24.04 -- uname -a
wsl -d Ubuntu-24.04 -- cat /etc/os-release
```

设置默认用户与 systemd：

```powershell
wsl -d Ubuntu-24.04 --user root -- bash -lc "printf '[boot]\nsystemd=true\n\n[user]\ndefault=ubuntu\n' > /etc/wsl.conf && chmod 644 /etc/wsl.conf"
wsl --terminate Ubuntu-24.04
wsl -d Ubuntu-24.04 -- bash -lc "id; printenv | grep -E '^(USER|DISPLAY|WAYLAND_DISPLAY|XDG_RUNTIME_DIR|PULSE_SERVER)='"
```

安装 GUI 测试工具：

```powershell
wsl -d Ubuntu-24.04 -- bash -lc "sudo apt update && sudo apt install -y x11-apps mesa-utils"
wsl -d Ubuntu-24.04 -- bash -lc "xclock"
wsl -d Ubuntu-24.04 -- bash -lc "glxinfo -B"
```

Windows 虚拟化状态：

```powershell
Get-CimInstance -ClassName Win32_Processor |
  Select-Object Name,VirtualizationFirmwareEnabled,VMMonitorModeExtensions,SecondLevelAddressTranslationExtensions
Get-CimInstance -ClassName Win32_ComputerSystem |
  Select-Object HypervisorPresent,Manufacturer,Model
```

管理员 PowerShell 中待执行：

```powershell
dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
bcdedit /set hypervisorlaunchtype auto
wsl --update
```

以上管理员步骤用于处理 `0x80370114` / `HCS_E_SERVICE_NOT_AVAILABLE` 一类 WSL2 后端问题。

## 2026-06-10 ROS2 Jazzy

检查系统：

```powershell
wsl -d Ubuntu-24.04 -- lsb_release -a
```

设置 locale：

```bash
sudo apt update
sudo apt install -y locales software-properties-common curl gnupg2
sudo locale-gen en_US en_US.UTF-8
sudo update-locale LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8
```

添加 ROS2 清华源：

```bash
sudo add-apt-repository -y universe
sudo rm -f /usr/share/keyrings/ros-archive-keyring.gpg
curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key \
  | sudo gpg --dearmor --yes -o /usr/share/keyrings/ros-archive-keyring.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] https://mirrors.tuna.tsinghua.edu.cn/ros2/ubuntu noble main" \
  | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null
sudo apt update
```

升级并安装：

```bash
sudo apt upgrade -y
sudo apt install -y ros-jazzy-desktop
sudo apt install -y ros-dev-tools
```

配置环境：

```bash
grep -qxF 'source /opt/ros/jazzy/setup.bash' ~/.bashrc || echo 'source /opt/ros/jazzy/setup.bash' >> ~/.bashrc
source /opt/ros/jazzy/setup.bash
```

初始化 rosdep：

```bash
sudo rosdep init
rosdep update
```

验证：

```bash
ros2 run demo_nodes_cpp talker
ros2 run demo_nodes_py listener
ros2 run turtlesim turtlesim_node
ros2 run turtlesim turtle_teleop_key
rviz2
```

## 2026-06-11 ROS2 开发基础

创建工作空间：

```bash
mkdir -p ~/ros2_ws/src
cd ~/ros2_ws
```

创建 Python 功能包：

```bash
cd ~/ros2_ws/src
ros2 pkg create --build-type ament_python my_package --dependencies rclpy std_msgs
```

编译：

```bash
cd ~/ros2_ws
colcon build --symlink-install
```

加载环境：

```bash
source /opt/ros/jazzy/setup.bash
source ~/ros2_ws/install/setup.bash
```

运行节点：

```bash
ros2 run my_package learning_talker
```

验证话题：

```bash
ros2 topic echo /learning_chatter --once
ros2 pkg executables my_package
```

自动加载工作空间 overlay：

```bash
echo 'if [ -f ~/ros2_ws/install/setup.bash ]; then source ~/ros2_ws/install/setup.bash; fi' >> ~/.bashrc
```

克隆 ROS2 examples：

```bash
cd ~/ros2_ws/src
git clone --branch jazzy --depth 1 https://github.com/ros2/examples.git
cd ~/ros2_ws
colcon list
```

安装并使用 tree：

```bash
sudo apt install -y tree
tree --charset ascii -L 3 ~/ros2_ws
ls -la ~/ros2_ws
```

检查环境变量：

```bash
env | grep -E '^(ROS_DISTRO|ROS_VERSION|ROS_DOMAIN_ID|AMENT_PREFIX_PATH|PYTHONPATH)='
```

选择性编译当前学习包：

```bash
cd ~/ros2_ws
colcon build --symlink-install --packages-select my_package
source install/setup.bash
ros2 pkg list | grep '^my_package$'
ros2 pkg executables my_package
```

## 2026-06-11 C++ 功能包创建与编译

创建 C++ 功能包：

```bash
cd ~/ros2_ws/src
ros2 pkg create --build-type ament_cmake my_cpp_pkg \
  --dependencies rclcpp std_msgs sensor_msgs geometry_msgs \
  --node-name my_node
```

编译指定包：

```bash
cd ~/ros2_ws
colcon build --symlink-install --packages-select my_cpp_pkg
```

编译多个包：

```bash
colcon build --symlink-install --packages-select my_package my_cpp_pkg
```

编译包及其依赖：

```bash
colcon build --packages-up-to my_cpp_pkg
```

编译修改过的包：

```bash
colcon build --packages-changed
```

运行 C++ 节点：

```bash
source /opt/ros/jazzy/setup.bash
source ~/ros2_ws/install/setup.bash
ros2 run my_cpp_pkg my_node
```

验证话题：

```bash
ros2 topic echo /cpp_chatter --once
ros2 pkg executables my_cpp_pkg
ros2 interface show std_msgs/msg/String
```

测试：

```bash
cd ~/ros2_ws
colcon test --packages-select my_cpp_pkg
colcon test-result --all
colcon test-result --verbose
```

清理命令，执行前必须确认在 `~/ros2_ws`：

```bash
rm -rf build/ install/ log/
rm -rf build/my_cpp_pkg/ install/my_cpp_pkg/
colcon build --cmake-clean-cache
colcon build --cmake-clean-first
find . -name "*.pyc" -delete
find . -name "__pycache__" -type d -exec rm -rf {} +
```

## 2026-06-11 服务与参数管理

查看自定义服务接口：

```bash
source ~/ros2_ws/install/setup.bash
ros2 interface show differential_drive_robot/srv/SetControlMode
```

启动仿真：

```bash
ros2 launch differential_drive_robot gazebo_harmonic.launch.py rviz:=false
```

查看服务：

```bash
ros2 service list | grep set_control_mode
```

调用服务切换控制模式：

```bash
ros2 service call /set_control_mode differential_drive_robot/srv/SetControlMode \
  '{mode: auto_circle}'
```

查看控制器参数：

```bash
ros2 param list /robot_controller
ros2 param get /robot_controller max_linear_speed
ros2 param set /robot_controller max_linear_speed 0.20
```

查看模式切换后的速度输出：

```bash
ros2 topic echo /cmd_vel --once
ros2 topic echo /odom --once
```

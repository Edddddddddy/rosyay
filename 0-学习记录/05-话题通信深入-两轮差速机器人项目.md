```text
  -> ros_gz_bridge
  -> Gazebo DiffDrive
  -> /odom        nav_msgs/msg/Odometry

  -> /joint_states sensor_msgs/msg/JointState
  -> robot_state_publisher
  -> /robot_description
  -> /tf_static
```

## 本次踩坑

### 1. PDF 的插件名需要按 Jazzy/Harmonic 调整

当前可用插件名是：

```xml
<plugin filename="gz-sim-diff-drive-system" name="gz::sim::systems::DiffDrive">
<plugin filename="gz-sim-joint-state-publisher-system" name="gz::sim::systems::JointStatePublisher">
```

### 2. `/cmd_vel` 使用 `TwistStamped`

Harmonic 当前桥接配置使用：

```text
geometry_msgs/msg/TwistStamped -> gz.msgs.Twist
```

所以 `robot_controller` 发布的是 `geometry_msgs/msg/TwistStamped`。

### 3. URDF 根 link 不建议带惯性

第一次 `base_link` 作为根 link 且带惯性时，`robot_state_publisher` 报 warning：

```text
The root link base_link has an inertia specified in the URDF
```

处理方式：

- 增加无惯性的 `base_footprint` 根 link。
- 用固定关节连接 `base_footprint -> base_link`。
- DiffDrive 的 `child_frame_id` 改成 `base_footprint`。

### 4. Gazebo parser warning 不等于失败

仍能看到几条：

```text
Warning [parser_urdf.cc:1220] Attribute value string not set
```

但实体创建、桥接、`/odom`、`/joint_states`、TF 都正常，因此暂时记录为非阻塞 warning。

# 06 服务与参数管理

日期：2026-06-11

参考教程：

- `ros2-doc/4-服务与参数管理/4-服务与参数管理.pdf`

## 本次目标

在上一节 `differential_drive_robot` 的基础上，把简单话题控制升级成控制框架：

- 键盘节点发布遥控命令和控制模式。
- 控制器节点支持多种控制模式。
- 使用 ROS2 service 切换模式。
- 使用 ROS2 parameter 管理速度、安全距离、墙面跟随参数。
- 保持 Gazebo 仿真可运行、可验证。

## 已实现内容

### 1. 新增自定义服务

文件：

```text
ros2-src/differential_drive_robot/srv/SetControlMode.srv
```

内容：

```srv
string mode
---
bool success
string message
```

服务名：

```text
/set_control_mode
```

支持模式：

```text
manual
auto_forward
auto_circle
obstacle_avoidance
wall_following
```

### 2. 参数配置文件

文件：

```text
ros2-src/differential_drive_robot/config/controller_params.yaml
```

核心参数：

```yaml
max_linear_speed: 0.26
max_angular_speed: 1.82
max_linear_acceleration: 0.5
max_angular_acceleration: 1.0
command_timeout: 0.7
obstacle_stop_distance: 0.45
wall_target_distance: 0.55
wall_kp: 1.0
control_rate: 20.0
```

这些参数在 `gazebo_harmonic.launch.py` 中加载给 `robot_controller`。

### 3. KeyboardController 升级

`teleop_keyboard.cpp` 从简单速度发布器升级为：

- 发布 `/teleop_cmd`：`geometry_msgs/msg/TwistStamped`
- 发布 `/control_mode`：`std_msgs/msg/String`

按键：

```text
w/x: 前进/后退
a/d: 左转/右转
s/空格: 停止
1: manual
2: auto_forward
3: auto_circle
4: obstacle_avoidance
0: wall_following
q: 退出
```

### 4. RobotController 升级

`robot_controller.cpp` 新增：

- 订阅 `/teleop_cmd`
- 订阅 `/control_mode`
- 订阅 `/scan`
- 订阅 `/odom`
- 订阅 `/joint_states`
- 发布 `/cmd_vel`
- 提供 `/set_control_mode` 服务
- 支持参数动态更新
- 支持速度限制和速度平滑
- 支持安全检查和紧急停车

控制模式：

- `manual`：使用键盘遥控命令。
- `auto_forward`：自动直行。
- `auto_circle`：自动圆形运动。
- `obstacle_avoidance`：前方近距离障碍时转向，否则前进。
- `wall_following`：根据右侧距离做简单墙面跟随。

说明：当前自制机器人模型还没有真实雷达，但控制器已经兼容 `/scan`。没有 `/scan` 时自动模式仍可运行；后续加雷达后安全逻辑会自动生效。

必须在 Ubuntu/WSL 的 Bash 终端中执行，并确保当前终端已经 source 工作空间。
推荐使用上面的一行命令；PowerShell 不使用 `\` 作为续行符，直接粘贴多行 Bash
命令会失败。

如果仍然失败，按顺序检查：

```bash
ros2 pkg prefix differential_drive_robot
ros2 interface show differential_drive_robot/srv/SetControlMode
ros2 node list | grep robot_controller
ros2 service list -t | grep set_control_mode
ros2 service type /set_control_mode
```

正确结果应包含：

```text
/robot_controller
/set_control_mode [differential_drive_robot/srv/SetControlMode]
```

如果接口存在但服务不存在，说明 `robot_controller` 没有成功运行；如果接口也找不到，
通常是当前终端没有 source `~/ros2_ws/install/setup.bash`，或工作空间没有重新编译。

结果：

## 本次踩坑

### 1. 自定义 service 需要 `rosidl_default_generators`

`CMakeLists.txt` 中新增：

```cmake
find_package(rosidl_default_generators REQUIRED)
rosidl_generate_interfaces(${PROJECT_NAME}
  "srv/SetControlMode.srv"
)
rosidl_get_typesupport_target(cpp_typesupport_target ${PROJECT_NAME} "rosidl_typesupport_cpp")
target_link_libraries(robot_controller "${cpp_typesupport_target}")
```

`package.xml` 中新增：

```xml
<buildtool_depend>rosidl_default_generators</buildtool_depend>
<exec_depend>rosidl_default_runtime</exec_depend>
<member_of_group>rosidl_interface_packages</member_of_group>
```

### 2. `member_of_group` 在 `package.xml` 里的位置有要求

一开始放到 `<export>` 后面，`xmllint` 报错：

```text
Element 'member_of_group': This element is not expected.
```

修复：放到 `<export>` 前面。

### 3. uncrustify 对换行和缩进很严格

测试会给出精确 diff，按它提示改即可。

### 4. 当前模型还没有雷达

控制器已经订阅 `/scan`，但自制 URDF 还没有加激光雷达插件。后续可以继续扩展传感器模型，让 `obstacle_avoidance` 和 `wall_following` 更真实。

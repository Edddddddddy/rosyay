## 对比结论

### 1. 差速机器人

我们的 `differential_drive_robot` 已经超过课程基础版：

- 适配 Gazebo Harmonic 当前插件名。
- 使用 `TwistStamped`，更贴近 Jazzy/TurtleBot3 当前接口。
- 增加 `base_footprint -> base_link`，规避 root link inertia warning。
- 增加 `config/bridge.yaml`、`controller_params.yaml`、RViz 配置。
- 增加自定义服务 `SetControlMode.srv`。
- 增加动态参数更新回调。
- 已通过 `colcon test`。

仍可补强：

- 增加显式 `stop` 控制模式。
- 增加墙跟随 PID 的 `ki/kd`，目前主要是 P 控制。
- 增加自动化仿真测试脚本，验证不同模式下 `/odom` 是否确实变化。
- 增加传感器数据可视化 marker，便于观察避障逻辑。

### 2. 服务与参数

我们的项目把 service/parameter 直接整合进真实机器人控制器，这是优点。

课程 `parameter_demo` 更适合作为学习样例，覆盖更完整：

- 参数描述符。
- 参数分组，如 `navigation.*`、`sensors.*`、`control.*`。
- 参数事件订阅。
- 参数客户端。
- 导出参数 YAML。

仍可补强：

- 给 `differential_drive_robot` 参数补描述符和范围约束。
- 增加一个参数客户端节点或脚本，专门演示运行时调参。
- 文档中补 `ros2 param dump`、`ros2 param load` 的实践。

### 3. Navigation2

我们的 `nav2_cpp_tutorial` 更贴近官方 Nav2 工程链路：

- 使用 `nav2_msgs/action/NavigateToPose`。
- 使用 `nav2_bringup`。
- 适配 Jazzy 默认启动的 `velocity_smoother`、`collision_monitor`、`docking_server`。
- 冒烟验证已跑到 `lifecycle_manager_navigation: Managed nodes are active`。

课程 `turtle_bot3` 更偏算法教学链路：

- `sensor_processor`：处理 `/scan`、`/imu`、`/odom`，发布障碍物 marker、特征点 marker、环境信息。
- `path_planner`：订阅 `/map`、目标点、初始位姿，实现 A* 路径规划并发布 `/planned_path`。
- `navigation_manager`：订阅 `/planned_path`、`/odom`、`/scan`，做路径跟随和紧急避障。
- `keyboard_controller`：支持多模式控制。

仍可补强：

- 完成一次 RViz `2D Goal Pose` 的真实导航到点验证。
- 让 `nav2_simple_test` 在完整启动后自动发送目标并判断结果。
- 增加自研 `sensor_processor`、`path_planner`、`navigation_manager` 练习包，用于理解 Nav2 内部思想。
- 增加自定义 RViz 配置，显示 `/map`、`/scan`、`/planned_path`、障碍物 marker、Nav2 状态。

## 课程源码自身需要注意的问题

课程源码可作为参考，但不要直接全量复制：

- `turtle_bot3` 目录里包含 `build/`、`install/`、`log/`，这些是生成物，不建议纳入我们的项目。
- `turtle_bot3/launch/complete_navigation.launch.py` 引用了 `maps/turtlebot3_world.yaml` 和 `rviz/navigation_tutorial.rviz`，但当前仓库源码层面没有看到对应目录，启用 `navigation:=true` 或 RViz 配置时可能需要补文件。
- `path_planner` 里 `dijkstra` 分支当前返回的是 `plan_astar()`，还不是独立 Dijkstra 实现。
- `navigation_manager` 发布的是 `geometry_msgs/msg/Twist` 到 `/cmd_vel`，在 Jazzy + TurtleBot3 场景下可能需要改成 `TwistStamped` 或增加转换节点。
- `turtle_bot3/CMakeLists.txt` 里有硬编码 include 路径 `/opt/ros/jazzy/include/tf2_geometry_msgs`，可移植性一般。
